# 🗂️ Dice Game 🎲

A simple Dice Game built with HTML, CSS, and JavaScript. It handles user input/events to roll dice, uses array/logic to determine results, and updates the UI.

## ✅ Key Features
- Event handling (click to roll)
- Random dice roll using JavaScript
- Conditional logic for game result (win/lose/draw — add your rules)
- User interface updates (show dice + score)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ How to Run
Open `index.html` in your browser.
